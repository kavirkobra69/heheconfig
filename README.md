## 📱 درباره پروژه

**HeheConfig** نسخه‌ای سفارشی از [v2rayNG](https://github.com/2dust/v2rayNG) است. هدف پروژه این است که کاربر هنگام ورود، روش دریافت کانفیگ را خودش انتخاب کند و برای به‌روزرسانی برنامه لازم نباشد هر بار به‌صورت دستی دنبال APK بگردد.

> این مخزن شامل پچ‌ها و اسکریپت‌های سفارشی و workflow ساخت است؛ سورس اصلی v2rayNG هنگام Build از مخزن upstream دریافت می‌شود.

## ✨ قابلیت‌ها

### 1. انتخاب روش ورود

در صفحه سفارشی برنامه دو گزینه وجود دارد:

- **GitHub** — دریافت کانفیگ از فایل `configs.json` مخزن GitHub؛ بدون نیاز به ورود به حساب تلگرام.
- **TelAccount** — استفاده از حساب تلگرام خود کاربر برای دسترسی به کانال‌ها و واردکردن کانفیگ‌ها از تلگرام.

این دو مسیر از هم جدا طراحی شده‌اند؛ انتخاب GitHub نباید به‌صورت خودکار ورود به تلگرام را آغاز کند.

### 2. حالت GitHub

- خواندن کانفیگ‌ها از `configs.json`.
- پشتیبانی از توکن GitHub برای عملیات مخزن که به دسترسی نوشتن نیاز دارند.
- مدیریت فهرست کانال‌ها و همگام‌سازی تغییرات با `telegram_channels.txt`.
- امکان آزمایش کانفیگ‌ها و درخواست تأیید کاربر پیش از حذف کانفیگ‌های ناموفق.

**نکته امنیتی:** توکن GitHub را در پیام‌ها، اسکرین‌شات‌ها یا فایل عمومی منتشر نکنید. در صورت نیاز، از Fine-grained Personal Access Token با دسترسی محدود به همین مخزن و مجوز `Contents: Read and write` استفاده کنید.

### 3. بخش Admin / Repository Manager

- ورود با GitHub Personal Access Token و ذخیره آن روی همان دستگاه برای استفاده‌های بعدی.
- دریافت فهرست Repositoryهایی که توکن به آن‌ها دسترسی دارد و انتخاب مخزن موردنظر.
- جست‌وجوی خودکار فایل `configs.json` یا `config.json` در مخزن انتخاب‌شده.
- پر کردن خودکار آدرس JSON برای واردکردن کانفیگ از مخزن انتخاب‌شده.
- بررسی ساختار JSON و پیشنهاد پاک‌سازی لینک‌های نامعتبر یا تکراری.
- اگر JSON خراب باشد، تلاش برای بازیابی لینک‌های شناخته‌شده و نمایش پیش‌نمایش تعداد موارد بازیابی‌شده پیش از ذخیره.
- فایل در GitHub فقط پس از تأیید صریح کاربر تغییر می‌کند؛ اگر هیچ لینک قابل‌بازیابی پیدا نشود، فایل دست‌نخورده می‌ماند.

**امنیت توکن:** توکن به‌صورت محلی در SharedPreferences ذخیره می‌شود و در نسخه فعلی رمزگذاری‌شده نیست. از توکن محدود به مخزن‌های لازم استفاده کن و در صورت گم‌شدن دستگاه، توکن را از GitHub لغو کن.

### 4. حالت TelAccount

- ورود به حساب تلگرام با اطلاعات API موردنیاز.
- انتخاب و مدیریت کانال‌های منبع کانفیگ.
- دریافت و واردکردن کانفیگ‌ها از تلگرام.
- ابزار پشتیبان‌گیری و بازیابی تنظیمات/نشست، در صورت وجود در نسخه ساخته‌شده.

**هشدار:** فایل پشتیبان نشست تلگرام حساس است. آن را در اختیار دیگران نگذارید و برای آن رمز قوی انتخاب کنید.

### 5. نسخه‌بندی و به‌روزرسانی درون‌برنامه‌ای

- نسخه فعلی برنامه در فایل `version.properties` نگه‌داری می‌شود؛ این فایل منبع اصلی `VERSION_NAME` و `VERSION_CODE` است.
- نسخه شروع این سیستم `1.0.1` با `versionCode=2` است. برای هر انتشار جدید، `VERSION_NAME` را بالاتر ببر و `VERSION_CODE` را نیز افزایش بده؛ سپس Push باعث Build و انتشار نسخه برچسب‌خورده مثل `v1.0.2` می‌شود.
- برنامه نسخه نصب‌شده را با نسخه آخرین Release مقایسه می‌کند. اگر نسخه جدیدتر نباشد، دانلود نمی‌کند؛ اگر جدیدتر باشد، APK همان Release را دانلود و نصب‌کننده Android را باز می‌کند.
- بررسی آخرین GitHub Release مخزن.
- پیدا کردن فایل APK در Release و دانلود آن داخل برنامه.
- باز کردن نصب‌کننده رسمی Android برای نصب نسخه جدید.

Android ممکن است لازم باشد اجازه نصب برنامه از این منبع را فعال کنید. **نصب بی‌صدا انجام نمی‌شود** و سیستم‌عامل برای تأیید نصب از کاربر اجازه می‌خواهد. برای به‌روزرسانی روی نسخه نصب‌شده، APK باید با همان شناسه برنامه و کلید امضای سازگار ساخته شده باشد.

### 6. جمع‌آوری خودکار کانفیگ‌ها

Workflow مربوط به جمع‌آوری، هر **۳ ساعت** اجرا می‌شود و کانفیگ‌های سازگار را از پیام‌های کانال‌های تعریف‌شده استخراج می‌کند. لینک‌های تکراری حذف می‌شوند و نتیجه در `configs.json` ذخیره می‌شود.

پروتکل‌های شناسایی‌شده در اسکریپت:
- `vmess://`
- `vless://`
- `trojan://`
- `ss://`
- `hysteria2://` و `hy2://`
- `tuic://`

اسکریپت حداکثر ۱۰۰۰ پیام اخیر هر کانال را بررسی می‌کند. کانال خصوصی فقط زمانی قابل دسترسی است که نشست تلگرام تنظیم‌شده به آن دسترسی داشته باشد.

## ⚙️ راه‌اندازی GitHub Actions

در تنظیمات مخزن به مسیر **Settings → Secrets and variables → Actions** بروید و این Repository Secrets را اضافه کنید:

| Secret | توضیح |
|---|---|
| `TG_API_ID` | API ID تلگرام |
| `TG_API_HASH` | API Hash تلگرام |
| `TG_SESSION` | نشست مجازشده تلگرام به‌شکل StringSession |

سپس کانال‌های موردنظر را در فایل `telegram_channels.txt` قرار دهید؛ هر کانال در یک خط. نام کاربری عمومی یا شناسه عددی کانال پشتیبانی می‌شود. برای شناسه‌های عددی، قالبی مانند `-100xxxxxxxxxx` معمولاً مناسب است.

> نشست تلگرام را فقط در GitHub Secrets قرار دهید؛ هرگز آن را مستقیماً در کد یا فایل‌های عمومی Commit نکنید.

## 📦 دریافت APK

1. وارد بخش [Actions](../../actions) شوید و آخرین اجرای **Build Telegram Import APK** را باز کنید.
2. اگر Build موفق بود، APK را از بخش Artifacts دانلود کنید؛ Artifacts به‌طور پیش‌فرض ۱۴ روز نگه‌داری می‌شوند.
3. در صورت موفقیت انتشار Release، فایل‌های APK در بخش [Releases](../../releases) نیز قرار می‌گیرند.

اگر آخرین Build هنوز در حال اجراست یا شکست خورده، APK همان Build را آماده فرض نکنید.

## 🧰 ساخت خودکار برنامه

Workflow ساخت، این مراحل را انجام می‌دهد:

1. دریافت سورس upstream از مخزن رسمی v2rayNG.
2. اعمال تغییرات سفارشی از پوشه `patches/` با `scripts/apply_patches.py`.
3. نصب ابزارهای Android SDK و NDK و تنظیم Java.
4. ساخت APK با Gradle.
5. ذخیره APKها به‌عنوان Artifact و تلاش برای انتشار آن‌ها در GitHub Release.

Build با Push تغییرات مرتبط به شاخه `main` یا اجرای دستی Workflow شروع می‌شود. برای انتشار یک نسخه جدید، حتماً هر دو مقدار `version.properties` را افزایش بده. اگر فقط کد عوض شود ولی شماره نسخه تغییر نکند، Release همان نسخه به‌روزرسانی می‌شود.

## 🗂️ ساختار مخزن

~~~text
.
├── .github/
│   └── workflows/
│       ├── build.yml                  # ساخت APK و انتشار Release
│       └── update-configs.yml         # جمع‌آوری زمان‌بندی‌شده کانفیگ‌ها
├── patches/
│   ├── TelegramSettingsActivity.kt    # صفحه انتخاب روش و تنظیمات
│   ├── TelegramManager.kt             # مدیریت ارتباط تلگرام
│   └── SessionBackup.kt               # پشتیبان‌گیری نشست
├── scripts/
│   ├── apply_patches.py               # اعمال پچ‌ها روی سورس upstream
│   └── collect_telegram_configs.py    # استخراج لینک‌ها از تلگرام
├── snippets/                          # قطعه‌کدهای کمکی اندروید/Gradle
├── telegram_channels.txt              # فهرست کانال‌های جمع‌آوری
├── configs.json                       # کانفیگ‌های جمع‌آوری‌شده
└── README.md                           # راهنما و مشخصات پروژه
~~~

## 🔄 فایل‌ها چه کاری انجام می‌دهند؟

| فایل | کاربرد |
|---|---|
| `patches/TelegramSettingsActivity.kt` | رابط انتخاب GitHub یا TelAccount، مدیریت کانال‌ها و بررسی به‌روزرسانی |
| `patches/TelegramManager.kt` | بخش اتصال و تعامل با تلگرام |
| `patches/SessionBackup.kt` | منطق پشتیبان‌گیری/بازیابی نشست در صورت ادغام در Build |
| `scripts/apply_patches.py` | انتقال پچ‌ها و تنظیمات لازم به سورس upstream |
| `scripts/collect_telegram_configs.py` | خواندن کانال‌ها و استخراج لینک‌های کانفیگ |
| `telegram_channels.txt` | کانال‌های منبع |
| `configs.json` | خروجی جمع‌آوری برای حالت GitHub |
| `.github/workflows/build.yml` | ساخت و انتشار APK |
| `.github/workflows/update-configs.yml` | اجرای دوره‌ای جمع‌آوری کانفیگ |

## 🔐 حریم خصوصی و مسئولیت استفاده

- اطلاعات ورود، API Hash، StringSession و توکن GitHub را عمومی نکنید.
- دسترسی جمع‌آوری کانال‌ها به مجوزهای حساب تلگرام تنظیم‌شده وابسته است.
- فقط از کانفیگ‌ها و سرویس‌هایی استفاده کنید که اجازه دسترسی و استفاده از آن‌ها را دارید.
- این پروژه بر پایه v2rayNG است؛ برای مجوزها و اطلاعات upstream به مخزن رسمی مراجعه کنید.
